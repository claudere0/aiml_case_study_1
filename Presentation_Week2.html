Week 2: Case Studies Portfolio

Анализ качества воздуха, NLP и выявление мошенничества


Команда: Абзал, Амир, Диас, Темирхан & Медет

Обзор Проекта

Мы выполнили 4 прикладные задачи, покрывающие полный цикл Data Science:

  • Task 1: Экология — Exploratory Data Analysis (EDA) для г. Павлодар
  • Task 2: Прогнозирование — Machine Learning для предсказания выбросов
  • Task 3: Обработка текста — NLP Pipeline для анализа тональности
  • Task 4: Финансовая безопасность — Работа с Imbalanced Data

Task 1: Качество воздуха в Павлодаре

Цель: Оценить исторический уровень загрязнения воздуха.

  • Оптимизация данных: из 3 ГБ сырых данных отфильтрованы только CSV файлы Павлодара (PM2.5, NO2, SO2).
  • Временные ряды (Time-series) сгруппированы по дням.
  • Выявлены сезонные пики в период отопительного сезона.
  • Рассчитаны дни превышения нормативов ВОЗ (15 µg/m³).

Task 2: ML-Прогнозирование выбросов

Цель: Создать модель предсказания уровня PM2.5 на следующий день.

  • Модель: Linear Regression (Линейная регрессия).
  • Инженерия признаков (Feature Engineering): использование "лагов" — исторического загрязнения за предыдущие 1-2 дня.
  • Модель способна заранее предупреждать о "грязных" днях, что критично для жителей промышленных городов.

Task 3: NLP Анализ тональности

Цель: Автоматическая классификация текстов (Позитив / Негатив).

  • Набор данных: Открытый датасет Movie Reviews (NLTK).
  • Предобработка: векторизация текста с помощью TF-IDF.
  • Алгоритм: Naive Bayes (MultinomialNB).
  • Результат: Высокая точность, применимость архитектуры для анализа отзывов на приложения банков и E-commerce.

Task 4: Выявление мошенничества

Цель: Поиск фрода в банковских транзакциях.

  • Проблема: Жесткий дисбаланс данных (99% легальных транзакций, 1% мошенников).
  • Решение: Использование алгоритма Random Forest с автоматической балансировкой весов (class_weight='balanced').
  • Метрики: Фокус смещен с общей точности (Accuracy) на матрицу ошибок (Confusion Matrix) для минимизации ложных блокировок легальных клиентов.

Заключение

  • Успешно применены методы EDA, Регрессии, NLP и классификации ансамблями.
  • Проект оптимизирован: размер директории сокращен в десятки раз.
  • Код повністю изолирован в виртуальной среде (venv) и готов к воспроизведению.
