# CSE-2506M: Week 2 Tasks & Case Studies

Привет, команда! В этой папке находятся выполненные задания для 2-й недели.
Мы значительно оптимизировали проект: удалили "тяжелые" архивы данных на 3 ГБ и оставили только необходимые CSV файлы для нашего города (Павлодар). Теперь проект весит всего пару мегабайт и быстро запускается!

## Структура папки
- `data/` — Здесь лежат очищенные данные по загрязнителям (PM2.5, PM10, NO2, и т.д.) только для г. Павлодар. Вам не нужно ничего скачивать или распаковывать, все уже готово!
- `Task_*.md` — Текстовые документы с описанием кейсов (заданий) по шаблону Case Study Task 1. (Это нужно для сдачи).
- `*.ipynb` — Рабочие скрипты (Jupyter Notebooks) с готовым кодом для всех четырех заданий.

## Описание Ноутбуков (Что нужно запустить)

1. **`Task1_AirQuality_Analysis.ipynb`**
   - **Цель:** EDA (Разведочный анализ) качества воздуха в Павлодаре.
   - **Что делает:** Читает данные из папки `data/`, строит графики по PM2.5, показывает превышение норм ВОЗ и матрицу корреляции между газами.
   
2. **`Task2_AirQuality_Prediction.ipynb`**
   - **Цель:** Машинное обучение для прогнозирования PM2.5 (Павлодар).
   - **Что делает:** Использует линейную регрессию, чтобы на основе вчерашних выбросов предсказать выбросы на завтра. Рисует график реальных значений и предсказаний.

3. **`Task3_Sentiment_Analysis.ipynb`**
   - **Цель:** NLP классификация тональности текста (Positive/Negative).
   - **Что делает:** Автоматически скачивает небольшой датасет отзывов через `NLTK`, векторизует текст (TF-IDF) и обучает модель Naive Bayes.
   
4. **`Task4_Fraud_Detection.ipynb`**
   - **Цель:** Обнаружение мошеннических транзакций (Несбалансированные данные).
   - **Что делает:** Генерирует синтетический финансовый датасет, где мошенников всего 1%. Показывает, как бороться с таким дисбалансом с помощью `RandomForestClassifier`.

## Как запустить?
1. Откройте нужный `.ipynb` файл в Jupyter Notebook, VS Code или Google Colab.
2. В случае с Task 1 и Task 2 убедитесь, что папка `data/` находится в одной директории с ноутбуками.
3. Нажмите **"Run All"** (Запустить все ячейки). Никаких дополнительных скачиваний не требуется.

Удачи на защите!
